A 24×24-grid pixel icon from pixelarticons, served from CDN and rendered pixelated.

```jsx
<Icon name="power" size={16} />
<Icon name="alert" size={24} color="#ffffff" />
```

Names must exist in pixelarticons (power, zap, sliders, save, folder, chart, close, reload, play, pause, alert, info-box, check, plus, minus, trash, search, clock, lock, eye, table, notes, download, upload, users, home, terminal is NOT available). Pass `color` only when the glyph must not be black — it routes through the tinting CDN.
